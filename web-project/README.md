# Web Project - Financial Report

## Overview
This project is a web application that presents a financial report for Old Dominion Freight Line. It includes an interactive dashboard with charts and metrics to analyze the company's financial performance.

## Project Structure
```
web-project
├── src
│   ├── index.html         # HTML structure of the web application
│   ├── styles
│   │   └── main.css       # CSS styles for the web application
│   └── scripts
│       └── main.js        # JavaScript code for interactivity and charting
└── README.md              # Documentation for the project
```

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, etc.)
- Internet connection (for loading external libraries)

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd web-project
   ```

### Running the Application
1. Open `src/index.html` in your web browser.
2. The application will load and display the financial report.

### Features
- Interactive charts using Chart.js
- Responsive design for various screen sizes
- Tabbed navigation for different sections of the report
